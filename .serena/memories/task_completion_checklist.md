# タスク完了時のチェックリスト

## 開発タスク完了時
1. **ビルド確認**
   ```bash
   ./gradlew build
   ```
   - コンパイルエラーがないこと
   - テストがすべてパスすること

2. **Docker環境での動作確認**
   ```bash
   docker-compose up -d
   curl http://localhost:8080/api/health
   ```
   - アプリケーションが正常に起動すること
   - ヘルスチェックが成功すること

3. **API動作確認** (該当する場合)
   - 関連するエンドポイントが正常に動作すること
   - レスポンス形式が正しいこと
   - エラーハンドリングが適切に機能すること

4. **コード品質チェック**
   - オニオンアーキテクチャの層分離が維持されていること
   - 適切なエラーハンドリングが実装されていること
   - 日本語コメントが記述されていること

5. **セキュリティチェック** (該当する場合)
   - 認証・認可が適切に実装されていること
   - SQLインジェクション対策がされていること
   - 機密情報がハードコードされていないこと

## リファクタリングタスク完了時
- `.claude/skills/refactoring.md` の確認事項に従う
- 既存のテストがすべてパスすること
- APIの互換性が維持されていること

## コミット前チェック
- [ ] ビルドが成功する
- [ ] テストが成功する
- [ ] 不要なコメントアウトコードを削除した
- [ ] デバッグ用のログ出力を削除した
- [ ] `.gitignore` に記載されたファイルを含めていない
- [ ] コミットメッセージが適切に記述されている

## プルリクエスト作成前
- [ ] `main` または `develop` ブランチの最新コードとマージ済み
- [ ] CI/CDパイプラインが成功すること
- [ ] APIドキュメントが更新されている（該当する場合）
- [ ] マイグレーションファイルが適切に作成されている（DB変更がある場合）
