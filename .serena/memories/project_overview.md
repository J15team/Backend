# J15 Backend プロジェクト概要

## プロジェクトの目的
Spring Boot 3.2 + Kotlin による学習管理バックエンドアプリケーション。
題材・セクション管理、ユーザー認証、進捗管理機能を提供するREST API。

## 技術スタック
- **言語**: Kotlin 1.9.21
- **フレームワーク**: Spring Boot 3.2.0
- **JDK**: Java 17
- **データベース**: PostgreSQL 16
- **ビルドツール**: Gradle 8.5
- **マイグレーション**: Flyway
- **セキュリティ**: Spring Security + JWT (jjwt 0.12.3)
- **レート制限**: Bucket4j 8.7.0 + Caffeine 3.1.8
- **ストレージ**: AWS S3 (画像アップロード)
- **コンテナ**: Docker, Docker Compose

## アーキテクチャ
オニオンアーキテクチャを採用（内側から外側へ）:
1. **Domain（ドメイン層）** - エンティティ、値オブジェクト、ドメインサービス
2. **Application（アプリケーション層）** - ユースケース、アプリケーションサービス
3. **Infrastructure（インフラストラクチャ層）** - リポジトリ実装、外部サービス連携
4. **Presentation（プレゼンテーション層）** - Controller、API エンドポイント

## 主要機能
- 認証機能（サインアップ/サインイン/JWT認証）
- 題材・セクション管理（CRUD操作、画像アップロード）
- 進捗管理（完了マーク、進捗取得）
- レート制限（60秒あたり100リクエスト）
- 管理者API（APIキーによる保護）
